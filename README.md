# ZenWeaver

ZenWeaver enables real-time, distributed audio processing via stream-processing architecture, auto-scaling, and a robust engine within a scalable platform.

With ZenWeaver, you get a lightweight tool that stays out of your way.

**What you get**

- ZenWeaver enables real-time, distributed audio
- processing via stream-processing architecture, auto-scaling,

- python

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ZenWeaver.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
